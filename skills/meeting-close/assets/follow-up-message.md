# Follow-up Message

Under 150 words. The decision comes first. Send it the same day.

---

**Subject:** [Meeting name]: decided [the decision in a few words]

Hi all,

**Decided:** [one sentence]. [Rule, e.g. "Dana made the call after hearing everyone."]

**Why:** [one sentence]

**Next:**
- [Name]: [what], by [date]
- [Name]: [what], by [date]

**Still open:** [item]. [Route: we will decide it in the thread by DATE / it goes on the DATE meeting / we are dropping it.]

**On the record:** [Name] preferred [position] because [reason]. We are going ahead anyway.

**Please check:** [anything that needed confirming]. Reply by [date] if this is wrong; otherwise we proceed.

[Sender]

---

Delete any line that does not apply. A message with no dissent has no "On the record" line, and a message with nothing to confirm has no "Please check" line.
